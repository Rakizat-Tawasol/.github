## About Us

**Rakizat Tawasol** is a software and systems development company based in Sheikh Zayed, Giza, Egypt. We build custom software, cloud ERP, and WhatsApp / Meta Business messaging infrastructure for specialized businesses, alongside licensed offline-first products such as **ZADENO** and **DAWIRX**.

We don't start with a generic platform and stretch it to fit. We start with how a specific industry actually operates — a pharmacy's batch and expiry-date tracking, a construction firm's Bill of Quantities, a restaurant's kitchen workflow — and build software around that reality.

Every product we maintain is built to:

- **Keep working whether or not the internet does** — offline-first by design.
- **Comply with regulation from day one** — not as an afterthought.
- **Grow with the business** — from a single branch to a multi-location operation, without a painful re-platforming project.

### Our Vision

To be the technology backbone that specialized businesses across **Egypt, the Gulf, and the wider Arab region** run on — replacing fragmented, generic tools with software built around how each industry actually operates, from the point of sale to the back office.
