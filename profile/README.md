## About Us

**Rakizat Tawasol** is a software and systems development company headquartered in Sheikh Zayed, Giza, Egypt, serving clients across **Egypt, the Gulf, the wider Arab region and international markets**.

We engineer complete digital foundations for businesses: enterprise AI security and governance, multi-tenant cloud ERP, WhatsApp and Meta Business messaging infrastructure, offline-first industry products, and custom software built around how each client actually operates.

We don't start with a generic platform and stretch it to fit. We start with how a specific industry works — a pharmacy's batch and expiry tracking, a construction firm's Bill of Quantities, a restaurant's kitchen workflow, an enterprise's AI agent risk — and build software around that reality.

Every system we deliver is built to:

- **Keep working whether or not the internet does** — offline-first and fail-closed by design.
- **Comply with regulation from day one** — e-invoicing, data protection and AI governance built in, not bolted on.
- **Scale with the business** — from a single branch to multi-location, multi-tenant and multi-region operations, without re-platforming.
- **Speak Arabic and English natively** — bilingual, RTL-ready interfaces from the ground up.

### Our Vision

To be the technology backbone that specialized businesses and enterprises across Egypt, the Gulf and the wider Arab region run on — replacing fragmented, generic tools with software engineered around how each industry actually operates, from the point of sale to the back office to the AI agents of tomorrow.

## Our Platforms & Products

### 🛡️ AgentGuard OS — Enterprise AI Agent Security, Governance & Runtime Control

> **Prevent · Control · Prove**

An independent control layer that sits between AI agents and the tools, models, data and systems they act on. Before any action runs, AgentGuard decides whether it is **allowed, denied, needs human approval or must be sanitized** — and proves every decision with tamper-evident evidence.

| Area | Capabilities |
|---|---|
| **Runtime enforcement** | Policy engine (YAML + CEL, Rego modules) with default-deny and fail-closed behavior · Ed25519-signed, rollback-protected policy bundles that keep enforcing offline · shadow mode, dry-run, historical replay and versioned rollback |
| **AI & MCP gateways** | OpenAI-compatible AI gateway with per-model policy, failover, caching, streaming and usage metering · MCP security gateway with tool pinning, rug-pull detection and output sanitization · agent-to-agent (A2A) proxy with signed delegation chains |
| **Content inspection** | Prompt-injection detection (English and Arabic), secrets and PII redaction, multimodal inspection of images, PDFs, Office documents, SVG and audio |
| **Agent coverage** | Any framework or model · computer-use and browser agents · coding-agent hooks · permission-aware RAG synced from SharePoint, Google Drive and Confluence · non-bypassable egress proxy and credential broker |
| **Detect & respond** | Incident auto-detection and containment, kill switch, playbooks · AI SOC copilot mapped to MITRE ATLAS and OWASP LLM · community threat intelligence · red-teaming library and CI release gate |
| **Evidence & compliance** | Hash-chained audit log, evidence vault and legal hold · controls for EU AI Act, NIST AI RMF, ISO/IEC 42001 & 27001, SOC 2 and OWASP Agentic, with automated compliance documentation |
| **Enterprise platform** | Multi-tenancy with PostgreSQL Row-Level Security and data-region pinning · OIDC/SAML SSO, SCIM, SPIFFE mTLS · application firewall · 500+ connector marketplace · SIEM, Slack, Teams and ticketing integrations |
| **Developer platform** | REST API with OpenAPI · SDKs for **Python, TypeScript, Go, Java and .NET** · [Terraform provider](https://github.com/Rakizat-Tawasol/terraform-provider-agentguard) · CLI · GitOps and Kubernetes operator · bilingual (Arabic/English) console, WCAG 2.2 AA |

**Open-source components:** [`agentguard-go`](https://github.com/Rakizat-Tawasol/agentguard-go) (Go SDK) · [`terraform-provider-agentguard`](https://github.com/Rakizat-Tawasol/terraform-provider-agentguard) (Terraform provider)
